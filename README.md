# Gym Membership System

## Overview

A simple Oracle database system for managing gym members, trainers, and training session bookings using SQL and PL/SQL.

## Features

- User management and access control.
- Trainer and member management.
- Training session booking and conflict prevention.
- Functions, stored procedures, and reports.
- Database views and automatic logging using triggers.
- Blocking and deadlock demonstrations.

## Database Tables

- `Trainers`
- `Members`
- `TrainingSessions`
- `TrainingSessions_LOG`

## Technologies

- Oracle Database
- Oracle SQL Developer
- SQL & PL/SQL

Demonstrate relational database design, database security, PL/SQL programming, and transaction management through a gym membership system.
